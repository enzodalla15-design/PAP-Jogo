# PAP-Jogo
Projeto do meu jogo Roblox para a PAP

Você é parte de um membro da tripulação de helicóptero e tem que salvar sobreviventes em uma cidade infestada de zumbis, ao mesmo tempo desbloqueando armas, personagens e helicópteros para ajudar-te a salvar mais sobreviventes.

No começo de uma missão o jogador vai sobrevoar um edifício ou outro scenario (caso tenha uma missão especial) 
onde primeiro vai ter que diminuir a horda de zumbis a escalar o edifício enquanto ele rodeia e atira nos zumbis alguns tentaram saltar no helicóptero para o danificar, o helicóptero aguenta un definido número de zumbis (helicópteros desbloqueados ao subir de níveis aguentaram mais zumbis) assim que o helicóptero conseguir reduzir o número de zumbis para aterrar irá mudar para a segunda fase da missão, onde têm que esperar que os sobreviventes embarque no helicóptero e ficar vigia para ver se algum zumbi sobe no telhado e tentam atacar os sobreviventes, nesta fase também tens que ficar de olho nas suas costas tem uma chance de que um zumbi tenha escalado por trás do helicóptero e tenta te agarrar tens de eliminar o zumbi antes que ele consiga chegar a ti.
